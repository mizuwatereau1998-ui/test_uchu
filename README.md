# 統計図版室

社会科教材編集向けの静的Web試作品です。公式CSVの取り込み、全国値を分母とする円グラフ、印刷向けPNG出力の基盤を実装しています。

**現在はCSV経路の試作品です。依頼の「1品目の公式統計を特定・取得し、実データから図版を生成する」段階は未完了です。** 開発環境のネットワーク制限で e-Stat・農林水産省へのHTTPS接続が403で拒否され、API仕様書・実際の統計表・公表形式を確認できていません。推測した数値、統計表ID、未確認のAPI実装は含めていません。アプリは空の状態で起動します。

## 起動

Node.js 22以上（テスト用）とPython 3（静的配信用）を使用します。アプリ自体に実行時のnpm依存やバックエンドはありません。

```sh
cd /workspace/test_uchu
npm ci --cache /tmp/stat-figures-npm-cache
npm start
```

ローカル端末で動かす場合はチェックアウト先へ移動して実行し、ブラウザでポート8000を開いてください。GitHub Pages等の静的ホスティングでも動作します。`file://` の直接起動はES Modulesの制約があるため非対応です。

APIキーは現在不要です。ソース・設定ファイル・localStorageへの秘密情報保存は行いません。

## CSVから図版を作る

1. 農林水産省またはe-Statから公式CSVと出典ページを取得します。公表主体が農林水産省であることを原表で確認してください。
2. 「公式CSVの取り込み」でファイルと文字コード（UTF-8 / Shift_JIS）を選びます。
3. 見出し行、都道府県列、**収穫量**の列を明示的に選びます。出荷量・産出額・面積等の列を選ばないでください。列名からの自動推測はしません。
4. 品目・統計年（年産）・単位・統計名・統計表ID・出典URL・確報／速報を原表から転記し、確認欄にチェックします。
5. 「検証して図版を作成」を押します。元データ一覧の47都道府県・全国値・出典を原表と照合します。
6. 上位3・5・10、配色、タイトル、文字サイズ、背景、出力サイズを選びPNGを保存します。
7. 「検証用JSONを保存」で、全都道府県の値、出典情報、計算結果、元CSVのファイル名・SHA-256・列指定・取り込み日時を保存できます。元CSVも別に保管してください。JSONを再読み込みする機能はまだありません。

### 対応するCSVの範囲

単一年・単一品目の表で、行に「全国」と47都道府県の正式名称（例：北海道、青森県、東京都）を持ち、収穫量が1列に並ぶ形式に対応しています。見出し前の説明行、UTF-8 BOM、CRLF、引用符内のカンマに対応します。プレビューは先頭8行です。

e-Statの多次元・縦持ちCSVや、地域コードのみのCSV等を無条件に取り込むものではありません。必要なら公式サイトの表表示・ダウンロード条件で品目・年次・項目を絞ってください。対応できない形式は、その公式ファイルを確認した上で専用アダプターを追加します。値の手入力による補完は行わないでください。

出典URLは `https://www.maff.go.jp/`、`https://www.e-stat.go.jp/`、`https://api.e-stat.go.jp/` の配下に限定しています。ただし、**ホスト名の検査だけでファイルの真正性や「収穫量」の意味を自動検証できるわけではありません**。現状は利用者による原表照合が必須です。出典情報もユーザー入力に基づきます。

### 計算と停止条件

- 降順に並べ、同値のときは都道府県コード順を使います。
- 割合は `都道府県の収穫量 / 原表の全国値 * 100`。全国値を都道府県合計で代用しません。
- 「その他」は `全国値 - 表示する上位都道府県の収穫量合計`。先に割合を丸めて引き算しません。
- 元の収穫量で計算し、割合の表示時だけ小数第1位に四捨五入します。表示割合の合計が100.0%にならない場合があります。
- 全国値と都道府県合計の差を画面に表示します。合計が全国値未満ならその差も「その他」に入ります。
- 全国値不在・非正数、都道府県不足・重複、欠測・秘匿記号、負値、都道府県合計が全国値を上回る場合は停止します。`-`、`x`、空欄、`…`等をゼロにはしません。
- 公表値の丸めで合計が全国値をわずかに超える場合も自動補正しません。原表の注記確認が必要です。

### PNG

横3200pxまたは1600px。高さはタイトル・凡例・出典の長さに合わせて変わります。円と凡例を別領域に配置し、上位10でも文字の衝突を防ぎます。出典URL・表ID・年産・確報／速報・単位・全国値・計算方法を画像に含めます。透明背景の文字色は暗色のため、淡い用紙や背景への配置を想定しています。

300dpiで配置するなら横3200pxは約271mm幅に相当します。PNGのDPIメタデータを300に設定する処理はなく、組版ソフトで配置寸法を指定します。OSの日本語フォントによって文字の見た目は変わります。

## 構成

```text
index.html / style.css        入力・設定・元データ一覧
src/app.js                   UI、ファイル読み込み、出力の制御
src/data/csv.js               CSV構文・欠測記号を含む数値の解釈
src/data/import.js            CSV列マッピング → 共通データモデル
src/domain/statistics.js      出典・件数・数値の検査、順位・割合・その他
src/charts/pie.js             Canvas円グラフとPNG用レイアウト
scripts/browser-test.mjs      実ブラウザ・PNG検証
scripts/check-official-access.sh  公式サイトへの読み取り接続確認
tests/statistics.test.js      計算・取り込み・異常値のテスト
docs/research.md              調査状況・未完了項目・再開手順
```

入力を共通モデル `{publisher, statistic, metric, item, year, unit, tableId, sourceUrl, publicationStatus, national, rows}` に変換した後、計算と描画を分離しています。API取得は将来 `src/data/` にアダプターを追加し、棒・折れ線・地図は `src/charts/` に描画モジュールを追加します。APIの返却構造や分類コードは公式仕様・メタ情報を確認してから実装します。

Canvasを使っているため、CDN・グラフライブラリのダウンロードなしに描画できます。Chart.jsは現段階では導入していません。

## 検証

```sh
npm test
# 別ターミナルで npm start を実行した状態で
npm run test:browser
```

ブラウザテストにはChromiumが必要です。この環境では `/usr/bin/chromium` を検証済みです。別環境では `CHROMIUM_PATH` にChrome/Chromiumの実行ファイルを指定できます。Playwrightは開発依存としてロックしています。

実施済み：

- 単体テスト4件：全国値による割合、上位3/5/10とその他、CSVと共通モデルの値の一致、欠測・重複等の拒否、丸め境界。
- Chromium：CSV取り込み、47件の表示、上位切り替え、JSONの出典・ハッシュ、実ダウンロードしたPNGの横3200pxと白／透明の画素、長いタイトル、最大文字サイズ、モバイル幅での横はみ出しなし。
- 出力・スクリーンショットは `artifacts/`（Git管理対象外）。

**テスト入力は合成値であり、公式統計ではありません。** 合成値はテスト内のみで生成し、アプリの初期データ・教材用サンプルとして配布していません。これらのテストは仕組みを検証しますが、実際の公式表との一致やAPIの稼働を証明するものではありません。公式CSVを入手した後に、原本の全国値・全都道府県値との照合テストを追加する必要があります。

## 実データ対応を完了するために

環境設定で `www.e-stat.go.jp`、`api.e-stat.go.jp`、`www.maff.go.jp` の通信許可を保存してください。許可追加の下書きは保存済みです。接続可能になった後、公式仕様と公表形式を調べ、1品目・実際の統計表IDを特定し、原CSVを保存して照合テストを追加します。現段階では実データ対応済みとは呼びません。詳細は [調査状況](docs/research.md) を参照してください。
