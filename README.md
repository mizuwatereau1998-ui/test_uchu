# 統計図版室

社会科教材編集向けの静的Webツール。**農林水産省の2024年産みかんの確報を使い、収穫量の円グラフとPNGを生成できます。** 既存の汎用CSV取り込み・配色・文字サイズ・タイトル変更・上位3/5/10・白／透明背景・横3200px出力を維持しています。

## 起動と操作

Node.js 22以上（検証用）とPython 3（静的配信用）を使用します。

```sh
cd /workspace/test_uchu
npm ci --cache /tmp/stat-figures-npm-cache
npm start
```

別の端末ではチェックアウト先に移動してください。ポート8000で静的配信します。特別なバックエンドは不要で、GitHub Pages等にも配置できます。ES ModulesとSHA-256検証のため、`file://`ではなくlocalhostまたはHTTPSで使用してください。

1. ページ上部の「検証済みデータを読み込む」を押します。外部APIには接続せず、同梱の公開統計データを読み込みます。
2. 元データ一覧の全国値・公表20府県・出典URLを確認します。未掲載27都道府県は「未掲載」と表示し、ゼロにはしません。
3. 上位3・5・10、配色、タイトル、文字サイズ、背景、出力サイズを選びPNGを保存します。**みかんの上位表示は、公表20府県内の順位です。** この範囲を画面とPNGに表示します。
4. 「検証用JSONを保存」で、元の値・出典・SHA-256・公表範囲・計算結果を保存できます。JSONの再読み込みは未対応です。

### 手動CSVの取り込み

- **みかんの検証済みCSV**：ページ上部から [抽出CSV](data/mikan-2024.csv) を保存し、「抽出CSVを手動で読み込む」で選びます。全国＋公表20府県を専用アダプターで読み込み、SHA-256が一致しないファイルは拒否します。メタ情報の手入力は不要です。
- **従来の汎用CSV**：下部の「公式CSVの取り込み」でファイル、文字コード（UTF-8 / Shift_JIS）、見出し行、地域列、収穫量列と出典情報を指定します。こちらは単一年・単一品目の全国＋47都道府県に対応し、欠測や不足を推測しません。出典・収穫量・年産・単位・確報／速報は利用者が原表で照合します。

みかんの原本は**公式Excel（XLSX）**です。同梱CSVは原本から機械抽出した派生物であり、政府が直接配布したCSVだとは扱いません。原本・変換手順・セル位置・両ファイルのハッシュを保存しています。任意の多次元e-Stat CSV、任意のExcelの直接アップロードは未対応です。

## 計算と実データの検証結果

割合は `収穫量 ÷ 559600 × 100`。表示時のみ小数第1位で四捨五入します。計算・円の角度には丸め前の値を使います。「その他」は `全国値 − 表示した上位府県の収穫量合計` です。

| 公表府県内の上位数 | 上位の収穫量合計 (t) | その他 (t) | その他の割合 |
| --- | ---: | ---: | ---: |
| 3 | 306,300 | **253,300** | **45.3%** |
| 5 | 399,500 | **160,100** | **28.6%** |
| 10 | 484,900 | **74,700** | **13.3%** |

上位5府県は和歌山141,700t（25.3%）、静岡88,500t（15.8%）、愛媛76,100t（13.6%）、熊本63,800t（11.4%）、佐賀29,400t（5.3%）です。

公表20府県の合計は **554,943t**、全国との差は **4,657t** です。この差は未掲載地域分や公表値の丸め差を含む残差として扱い、特定県へ割り振りません。未掲載県の収穫量・順位は不明であり、47都道府県の完全な順位を検証したとは主張しません。丸めた割合の合計は100.0%にならない場合があります。

全国値の不在・非正数、地域重複、欠測・秘匿記号、負値、公表県合計が全国値を上回る場合は停止します。`-`、`x`、空欄、`…`等をゼロにしません。20件の部分掲載を認めるのは、公表範囲を明示した専用データ経路です。汎用CSVの47件不足を許容する変更ではありません。

## e-Stat API 3.0の確認と認証境界

[公式API仕様ページ](https://www.e-stat.go.jp/api/api-info/api-spec) から [API仕様Ver3.0（2019年7月、PDF）](https://www.e-stat.go.jp/api/sites/default/files/uploads/2019/07/API-specVer3.0.pdf) を取得し、仕様を確認しました。詳細は [調査記録](docs/research.md)。

- JSONのGETエンドポイントは `/rest/3.0/app/json/getStatsList`（表検索）、`getMetaInfo`（分類・単位等）、`getStatsData`（実数値）。全APIで `appId` が必須。
- `getMetaInfo` / `getStatsData` の `statsDataId` には `0004046674` を使用します。収穫量を選ぶ分類コードや年次・地域コードは、認証後のメタ情報で確認してから使用します。未確認の分類コードは実装していません。
- ページングは `limit` / `startPosition` と応答の `NEXT_KEY`。`limit`省略時10万件。HTTPコードだけでなく `RESULT.STATUS` と全件取得の完了を検査します。

**認証情報はブラウザに入力・保存しません。GitHub公開コードにも含めません。** 現在のアプリは同梱公開データだけを利用し、APIキーを要求しません。将来の自動取得は、秘密を保有するサーバー側ジョブまたはローカルCLIからAPIを呼び、認証情報・リクエストURL・PARAMETERを含まない公開用データと出典マニフェストだけを出力する構成にします。ブラウザにAPIリクエストを中継してキーを露出する実装はしません。

### 通信・403の調査結果

2026-11-12、公開済み環境の許可設定が適用されていることを確認し、新しい接続で公式API案内・仕様PDF・MAFFページ・e-Statの表／ExcelをHTTP 200で取得しました。以前のCONNECT段階の403は再現していません。

認証情報の設定・注入がないことを名前・メタ情報のみで確認し、`getMetaInfo?statsDataId=0004046674` を**appIdを付けずに**一度照会しました。実応答は **HTTP 200 / RESULT.STATUS=100「認証に失敗しました。アプリケーションIDを確認して下さい。」**。通信拒否とは区別しています。仕様書の認証失敗はHTTP 403ですが、観測値は200だったため、STATUS検査が必要です。認証成功・APIの実数値取得は未検証です。

## 構成と残る課題

```text
src/data/csv.js, import.js    既存のCSV構文・汎用列マッピング
src/data/mikan.js             みかんの検証済みCSV → 共通モデル
src/domain/statistics.js      共通モデルの検査、順位・割合・その他
src/charts/pie.js             図形・凡例・注記・PNGレイアウト
src/app.js                    UI、読み込み、出力
scripts/extract-mikan.py      公式Excel → CSV、原本セルとの全件照合
data/mikan-2024-source.xlsx   公式原本（無改変）
data/mikan-2024.csv           再現可能な抽出CSV
data/mikan-2024.json          出典・ID・年次・単位・公表範囲・ハッシュ
```

将来のAPIアダプターも `{publisher, statistic, metric, item, year, unit, tableId, sourceUrl, publicationStatus, national, rows, coverage, provenance}` を出力し、CSVと同じ検査・計算・描画に渡します。認証付き取得と公開データ生成を分離し、描画側に通信・秘密の知識を持たせません。棒・折れ線・地図は `src/charts/` に追加できます。

未解決：APIの認証成功・メタ情報とCSVの分類コード照合・実値のAPI/原本比較・認証を安全に保持する取得ジョブは未実装です。今回CSV経路で検証した原本は2024年産であり、最新年の自動追従を保証しません。他品目、未掲載27県の個別値、全47都道府県の順位、任意のExcel／多次元CSVも未対応です。

PNGは1600px/3200pxで、出典・年産・単位・公表範囲・計算方法を含めます。横3200pxを300dpiで配置すると約271mm幅です。DPIメタデータの300指定処理はなく、組版ソフトで配置寸法を指定してください。日本語フォントはOSにより変わります。
